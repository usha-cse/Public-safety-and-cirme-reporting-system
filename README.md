# 🛡️ Public Safety and Crime Reporting System

A web-based application designed to help citizens report crime-related incidents and public safety concerns. The system combines web technologies and machine learning to support incident reporting and public safety management.

### ✨ Key Features
- Crime and incident reporting
- Report management
- Evidence handling
- Public safety alerts
- Machine learning integration

### 🛠️ Tech Stack
- *Frontend:* React
- *Backend:* Node.js, Express.js
- *Database:* MongoDB, Mongoose
- *ML Service:* Python, FastAPI
